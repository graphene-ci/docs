# AGENTS.md — docs

Единственная пользовательская документация Graphene. Технические README
репозиториев могут описывать только их назначение, сборку и проверку; модель
продукта, руководства и справочник живут здесь.

## Перед изменением

1. Прочитайте `../GRAPHENE.MD` и код поверхности, которую описывает страница.
2. Документируйте только проверенное текущее состояние. Не ведите changelog,
   список прошлых решений или обещания без реализации.
3. Любая пользовательская страница изменяется одновременно в английской и
   русской локалях с одинаковой структурой и ссылками.
4. Перед push выполните `make check`.

## Структура и стиль

- `docs/` — английский оригинал;
- `i18n/ru/docusaurus-plugin-content-docs/current/` — русская версия;
- `static/` — общие статические файлы;
- категории sidebar задаются `_category_.json` и должны совпадать между
  локалями;
- примеры команд обязаны существовать в текущем CLI/SDK;
- незавершённая возможность называется ограничением, а не доступной функцией;
- продуктовые утверждения проверяются по `../GRAPHENE.MD` и текущему коду.
