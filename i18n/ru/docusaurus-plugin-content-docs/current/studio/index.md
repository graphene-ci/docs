# Graphene Studio

Graphene Studio — самостоятельное операторское приложение для инсталляции
Graphene. Оно поставляется отдельно от сервера и подключается только через
публичный Management API, поэтому одна сборка Studio может работать с
несколькими именованными контекстами инсталляций.

Web-приложение хранит выбранные server, namespace и token локально в браузере.
Desktop build оборачивает тот же renderer в Electron и не добавляет приватный
серверный протокол.

## Текущее рабочее пространство

Сейчас Studio предоставляет:

- именованные контексты, проверку соединения, переключение namespace, темы и
  английский/русский UI;
- общее дерево ресурсов и inspectors для системных и принесённых библиотеками
  kinds;
- представления pipelines, sources, revisions, runs и agents;
- серверную материализацию read-only Git source, поток build output, draft-runs
  ревизий и их активацию;
- типизированный submit рана, rerun и cancel, живой execution trace и навигацию
  по принадлежащему рану поддереву;
- state записи, events, фильтрованные logs, charts метрик, traces, downloads,
  commands, transfer и delete в пределах прав вызывающего;
- топологию ownership и объявленных flows;
- интерактивный терминал подключённого агента.

Файлы Git source намеренно доступны только для чтения. Измените и закоммитьте
код в Git, синхронизируйте source-запись и материализуйте новую неизменяемую
ревизию.

## Подключение

Добавьте контекст с адресом единственной двери инсталляции и токеном. TLS —
обычный удалённый режим. Plaintext допустим только для локального dev-стека и
выбирается явно. Handshake выполняется до сохранения контекста, а ответ
`WhoAmI` сервера определяет доступные namespaces и actions.

Studio не обходит авторизацию: скрытые или отключённые в UI действия всё равно
проверяются тем же Management API, что использует `graphenectl`.

Продолжите с [подключения к инсталляции](./connect.md), затем выберите нужный
сценарий:

- [источники и pipelines](./pipelines.md) — синхронизировать Git, собрать
  revision, проверить её как draft и активировать;
- [runs и ресурсы](./runs-resources.md) — запускать и диагностировать работу,
  разбирать ownership, управлять records и открывать terminal агента.

## Текущие ограничения

Кнопки update и restart агента пока показаны как coming soon. Агент умеет
самообновляться, когда инсталляция раздаёт новый бинарь, но Studio ещё не
запускает этот lifecycle вручную. Studio также не редактирует Git source и не
настраивает внешние identity, secret и telemetry services инсталляции.

Локальная разработка и desktop packaging описаны в техническом README
репозитория [`studio`](https://github.com/graphene-ci/studio).
