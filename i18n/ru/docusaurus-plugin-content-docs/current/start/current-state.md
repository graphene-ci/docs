# Текущее состояние

Сегодня Graphene доступен как Go SDK пайплайна, development control plane,
`graphenectl`, агент Linux-машины, библиотеки ресурсов и операторский UI. Эта
страница отделяет поставленное поведение от будущей работы.

## Доступно сейчас

| Поверхность | Текущее поведение |
|---|---|
| Пайплайн | Go-программа с типизированными params и result; `plan`, `push` и managed `run` |
| Control plane | Durable-раны и записи ресурсов на Temporal; одна внешняя дверь сервера |
| Исходники | Read-only Git и локальная загрузка; неизменяемые материализованные ревизии |
| Машины | Исходящий Linux-агент, установка по SSH или cloud-init, отдельный `runc` executor рана |
| Ресурсы | Дерево владения, каскадный снос, stand/TTL, метки, выборка, команды и flows |
| Библиотеки | Docker, Kubernetes/Crossplane, доставка файлов, Git-действия, артефакты и действия на машине |
| Эксплуатация | Generic CLI, пять измерений наблюдаемости, RBAC, namespaces и service accounts |
| Studio | Web/Electron workspace поверх публичного Management API |

Начните с [локального плана](first-look.md), чтобы изучить модель без сервера,
или пройдите [development-запуск](end-to-end.md).

## Намеренные границы

- Пайплайны — Go-программы. Pkl, KCL и YAML-описания пайплайнов относятся к
  архивному проектированию и не являются интерфейсами продукта.
- Источник правок — Git. Graphene читает и собирает checkout, но не хранит
  редактируемые изменения поверх коммита.
- Executor-контейнер агента упаковывает пайплайн, но не изолирует его от хоста.
  Действия на машине получают настроенный доступ уровня хоста.
- Kubernetes — вариант размещения и цель ресурсов, а не обязательная
  зависимость control plane.
- Большие данные живут в артефактах или telemetry-бекендах, а не в результате
  рана и не в Temporal history.

## Пока не поставляется

| Ограничение | Практическое следствие |
|---|---|
| Production-дистрибутив | Репозиторий поставляет development Compose, а не hardened deployment |
| Встроенная петля `dev` | `pipeline dev` и `run --dev` возвращают явную ошибку not implemented |
| Multi-architecture workers | Self-build сейчас нацелен на Linux/amd64 |
| Автоматический bootstrap-обмен агента | Identity агента должна быть заранее настроена инсталляцией |
| Похороны умершей машины | Для записей на безвозвратно потерянной машине ещё нужен операторский инструмент |
| Контракт HA и disaster recovery | Поддерживаемая топология, sizing и SLA восстановления не опубликованы |

Эти пробелы нельзя заполнять выдуманными инструкциями. Перед публикацией
инсталляции за пределами development-сети прочитайте
[Совместимость](../operations/compatibility.md) и
[границу production](../operations/development-installation.md#безопасность-и-граница-production).

## Контракт документации

Страницы описывают поставленное поведение, а не roadmap. Возможность, которой
нет на сайте, не следует из старого репозитория, issue, макета или архива.
Фактический словарь инсталляции доступен через `graphenectl kinds` и
`graphenectl get kind/<name>`: он определяет доступные виды записей и команды.
